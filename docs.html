Quick Start

The Truwit API allows you to programmatically create and verify cryptographic proofs for digital content. 

# Create a proof from URL (coming soon)
curl -X POST https://api.truwit.ai/v1/proofs/url \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://youtube.com/watch?v=..."
  }'

# Response
{
  "proofId": "abc123def456...",
  "trustmarkId": "xyz789",
  "verifyUrl": "/t/xyz789",
  "contentHash": "a1b2c3d4...",
  "deduped": false
}

Embed Trust Badge

You can embed Truwit verification badges on your website today using an iframe: 

<iframe 
  src="https://truwit.ai/badge/{trustmarkId}" 
  width="200" 
  height="50" 
  frameborder="0">
</iframe>

Replace {trustmarkId} with your actual trustmark ID from the verification page.
