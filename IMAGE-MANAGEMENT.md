# Image Management Strategy

## Single Source of Truth: `app/src/assets/`

This is the **only** folder where you should add, update, or manage images.

## Image Folders Structure

### 1. **`app/src/assets/`** - PRIMARY SOURCE ✅
**Purpose:** Master copy of all images for Angular app  
**Maintained by:** Team (manually updated)  
**Used by:** Angular application  
**Build output:** `app/dist/humanproof-web/assets/`

### 2. **`public/images/`** - SYNCED COPY
**Purpose:** Images for Astro marketing site  
**Maintained by:** Automated sync from `app/src/assets/`  
**Used by:** Astro site (truwit.ai landing pages)  
**Build output:** Copied to Cloudflare Pages deployment

### 3. **`api/wwwroot/assets/`** - API ASSETS
**Purpose:** Static assets served by API (badges, proof cards)  
**Maintained by:** API generation scripts  
**Used by:** API endpoints (/assets/badges/, /cards/proof/)

## Why Separate Folders?

Angular and Astro use different build systems:
- **Angular:** Bundles assets during `ng build`, optimizes and adds to dist
- **Astro:** Copies public folder as-is to deployment
- **API:** Serves static files directly from wwwroot

They cannot share the same physical folder due to different build processes.

## How to Update Images

### Option 1: Manual Sync (Recommended for now)
1. Update/add images in `app/src/assets/`
2. Run sync command:
   ```powershell
   xcopy /Y /I app\src\assets\*.* public\images\
   ```
3. Commit both folders

### Option 2: Automated Sync Script
Run the sync script before committing:
```powershell
.\sync-images.ps1
```

## Image Usage Guidelines

### Size Requirements
- **Header logo:** 32×32px
- **Footer badge:** 48×48px
- **Feature icons:** 48×48px (used on landing/verify pages)
- **Proof badges:** 800×800px, 640×640px, 1024×1024px (generated by API)

### Format Guidelines
- **Logos:** SVG (scalable) or PNG (with transparency)
- **Badges:** JPG or PNG (circular, transparent background preferred)
- **Banners:** PNG (high resolution for marketing)

```

### Astro Build

npm run build
# Copies public/images/ to: dist/images/
```

- **Cloudflare Pages (Angular /app):** Uses bundled `assets/` from build

## Troubleshooting

### Image not showing after update?
1. Check if image exists in `app/src/assets/`
2. Run sync script to copy to `public/images/`
3. Verify image path in code
4. Clear browser cache
5. Check build output folders

### Wrong image version?
- Delete old versions from both folders
- Add new version to `app/src/assets/`
- Run sync script
- Commit both changes

## Best Practices

✅ **DO:**
- Always update images in `app/src/assets/` first
- Run sync script before committing
- Use descriptive file names
- Optimize images before adding (compress, proper dimensions)
- Use SVG for logos when possible
- Document image purpose if not obvious

❌ **DON'T:**
- Don't directly edit `public/images/` (it gets overwritten)
- Don't add images to root `/images/` folder (deleted)
- Don't commit without syncing both folders
- Don't use spaces in image filenames
- Don't commit huge unoptimized images
